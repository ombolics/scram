# Roadmap

- [x] Pick loader and Minecraft version (NeoForge, 1.21.1)
- [x] Gradle scaffold: `sim` and `mod` modules, first unit test (mod module still to be verified)

- [ ] Recipes and advancements gating progression

## Later
